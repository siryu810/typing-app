# MVP 受け入れチェックリスト

実装の完了条件。すべて満たしたら MVP 完了とする。

## 画面

- [ ] ホーム: タイトル、世界観の一文、「業務を開始する」、タイピング分析は「準備中」
- [ ] 難易度: 新米 / 一人前 / つよつよの3カード。制限時間90秒と返信の傾向が分かる
- [ ] タイピング: 左レール（年収・COMBO・成長・WPM・正確率・ミス・残り）＋右チャット＋下入力
- [ ] 結果: 最終年収、WPM、正確率、ミス、最大連続。「もう一度」は難易度選択、「ホーム」に戻れる。分析は準備中

## 進行

- [ ] ホーム → 難易度 → タイピング →（90秒で時間切れ）→ 結果
- [ ] 打ち切りで自動送信 → 報酬加算 → 年収・COMBO更新 → 次のチャット
- [ ] 時間切れ時の途中入力は未送信（スコアに含めない）
- [ ] 結果から「もう一度」で難易度選択、「ホーム」でホーム

## スコア

- [ ] 基本給 300 / 450 / 600 万
- [ ] 件ごと基礎 +12 / +22 / +38 万に、その件の速度・正確率で増減
- [ ] セッション全体の WPM・正確率・ミス・最大連続を結果に表示
- [ ] COMBO は正解キー連続、ミスでリセット
- [ ] 成長ゲージは送信件数から算出

## ローマ字

- [ ] 日本語＋正規化ローマ字を1通り表示
- [ ] 正解 / ミス / 現在 / 未入力を色分け
- [ ] 一般的な別表記（shi/si 等）を入力として許容
- [ ] 判定はクライアント完結（キー入力で API を呼ばない）

## D1 / API

- [ ] 開始時に `GET /api/problems?difficulty=` のみ
- [ ] 終了時に `POST /api/plays` を1回（`anonymousId` を含む）
- [ ] 匿名IDは localStorage。ログインなし、個人情報なし
- [ ] ローカル D1 と本番 D1 が分離されている

## 品質と公開

- [ ] `just check`（`vp check && vp test && vp build`）が通る
- [ ] ローマ字判定と報酬計算の単体テストがある
- [ ] ローカルで90秒プレイできる（問題取得→送信加算→時間切れ→結果保存）
- [ ] GitHub 公開リポジトリ `siryu810/typing-app` に main が push されている
- [ ] 本番デプロイできていれば `*.workers.dev` でプレイできる（要 wrangler login / D1 create）
- [ ] GitHub Actions は使っていない
