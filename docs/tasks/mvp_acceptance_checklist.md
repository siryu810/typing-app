# MVP 受け入れチェックリスト

実装の完了条件。すべて満たしたら MVP 完了とする。

## 画面

- [x] ホーム: タイトル、世界観の一文、「業務を開始する」、タイピング分析は「準備中」
- [x] 難易度: 新米 / 一人前 / つよつよの3カード。制限時間90秒と返信の傾向が分かる
- [x] タイピング: 左レール（年収・COMBO・成長・WPM・正確率・ミス・残り）＋右チャット＋下入力
- [x] 結果: 最終年収、WPM、正確率、ミス、最大連続。「もう一度」は難易度選択、「ホーム」に戻れる。分析は準備中

## 進行

- [x] ホーム → 難易度 → タイピング →（90秒で時間切れ）→ 結果
- [x] 打ち切りで自動送信 → 報酬加算 → 年収・COMBO更新 → 次のチャット
- [x] 時間切れ時の途中入力は未送信（スコアに含めない）
- [x] 結果から「もう一度」で難易度選択、「ホーム」でホーム

## スコア

- [x] 基本給 300 / 450 / 600 万
- [x] 件ごと基礎 +12 / +22 / +38 万に、その件の速度・正確率で増減
- [x] セッション全体の WPM・正確率・ミス・最大連続を結果に表示
- [x] COMBO は正解キー連続、ミスでリセット
- [x] 成長ゲージは送信件数から算出

## ローマ字

- [x] 日本語＋正規化ローマ字を1通り表示
- [x] 正解 / ミス / 現在 / 未入力を色分け
- [x] 一般的な別表記（shi/si 等）を入力として許容
- [x] 判定はクライアント完結（キー入力で API を呼ばない）

## D1 / API

- [x] 終了時に `POST /api/plays` を1回（`anonymousId` を含む）

- [x] ローカル D1 と本番 D1 が分離されている
