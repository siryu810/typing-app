# ADR 0001: ローマ字別表記の受け入れ

## 状態

採用

## 文脈

表示用ローマ字は正規化1通り（ヘボン式寄り）とする。一方、日本語ローマ字入力では `shi` / `si` のように複数の打ち方が一般的で、正規化1通りだけを正解にすると誤判定が増える。

## 決定

- **表示**は問題の読みから生成した正規化ローマ字1通りのみ
- **入力判定**は、残りの読みに対して一般的なローマ字別表記をすべて許容する
- 判定はクライアントの共有モジュールで行い、キー入力ではサーバーと通信しない

許容する例:

- `shi` / `si`、`chi` / `ti`、`tsu` / `tu`、`fu` / `hu`
- `sha` / `sya`、`shu` / `syu`、`sho` / `syo` およびちゃ行・じゃ行の同様の揺れ
- `ji` / `zi`、`zu` / `du`
- 促音は次子音の重ね（`kk` など）
- んは子音前 `n`、母音前は `nn` または `n'`

英数字・記号・改行はそのままのキー。

## 結果

表示は安定し、入力は一般的な打ち方で進められる。正規化文字列との1:1比較はしない。
